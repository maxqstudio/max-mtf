# CPMF v0.7.5 R5 — Scientist/Supervisor Creativity Parity Repair

R5 closes the creativity/context gaps found after R4 deterministic Discovery parity.

Repairs:

1. adds deterministic Adaptive Creativity Governor with evidence-aware `BALANCED`, `LOCAL_REFINEMENT`, `STRUCTURAL_ESCAPE`, `BROADEN_SEARCH`, and `STABILITY_REPAIR` modes;
2. replaces raw Owner-facing LLM temperature as the scientific-creativity authority with bounded `Scientific creativity` plus phase-aware temperatures;
3. applies `LLM research influence` consistently to exploration and family-priority weighting;
4. gives round Scientist the same hardware/capacity/topology/compute/seed-policy context classes as the Factory Research Director;
5. propagates CPCV multi-seed confirmation evidence into Scientist-visible failure topology/Research Memory;
6. adds executable deterministic `SEED_STABILITY` hypotheses for stochastic instability without changing the fixed `42/11/77` seed set;
7. turns dynamic `HYBRID_ABLATION` into a controlled executable standalone-vs-hybrid Experiment Block when both topology arms are Owner-authorized;
8. makes hybrid-ablation proxy support depend on incremental hybrid hard-gate survival over its standalone control, rather than any candidate PASS in the block;
9. suppresses arbitrary LLM candidate injection while a deterministic paired hybrid-ablation block owns the experiment arms;
10. preserves all R4 deterministic Discovery/capacity/KPI/chronology/locked-Forward authorities.

Creativity changes experiment selection and breadth only. It never changes PASS/FAIL.
